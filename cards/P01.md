## Dan 1 — Zadatak 1

```bash
gh repo clone fesbracingteam/git-radionica
cd git-radionica
make run
git checkout -b p01-korak-1
cp templates/tema.c topics/p01.c     # uredi: p01, "Nogomet", pitanje
git add .
git commit -m "Dodaj pitanje"
# registry.c: ispod oznake TIM A upiši   &topic_p01,
git add registry.c
git commit -m "Upisi temu u registar"
git commit --amend -m "Upiši temu u registar"
git rm legacy/junk_01.txt
git commit -m "Obriši staru datoteku"
make check
git log
git push -u origin p01-korak-1
```
